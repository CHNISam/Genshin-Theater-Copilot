# 历期事实档案

[月度索引](../seasons/history/index.json)覆盖2024-07至2026-10的28个正式月度槽位。这里的“覆盖”指每个月都有档案与缺口状态，不表示28期资料完整，更不表示历史通关验证。

2024-07至2026-08的26期已从BWIKI实际下载的事实归档页提取三种限定元素、六名开幕角色、四名特邀角色，以及固定首领/圣牌表。首两期各3个首领节点；2024-09至2025-09各4个；2025-10起各4个首领和2个圣牌节点。2026-09由两份可读的7.0更新公告转载补齐元素、开幕、特邀身份，固定敌人仍缺失；2026-10从仓库已有正确期次资料包导入身份、六个固定目标和已取得的少量增益片段。28期均保持`PARTIAL_FACTS`：普通随机敌人池、完整当期增益树与机制参数仍缺失，来源可靠级别也有区别。

## 实际阅读与来源

前18期使用`幻想真境剧诗/第X期`独立页面；2026年前8期使用`幻想真境剧诗/2026`的第19至26期段落。所谓`/2024`、`/2025`年页实际返回404，不能把推测网址当作已读来源。若普通路径返回567，`index.php?title=...`路径取得了正文。每个JSON登记实际URL、段落定位、访问日期、当前revision_id与事实片段HTML的SHA-256；片段保存在[证据目录](../seasons/history/evidence/)。片段保留图标alt、表格与链接，以便检查无文本的角色/元素单元格。

BWIKI由玩家维护，属于社区事实归档，并非官方原始公告。本文中的“正式月度槽位”描述游戏期次，不描述来源官方身份。引用、改编的BWIKI资料按其CC BY-NC-SA 4.0协议归属原神WIKI/BWIKI、旅行者酒馆和页面贡献者。9月事实来自[原神资讯站转载](https://genshininfo.reh.tw/archives/10263)和[九游转载](https://h5.9game.cn/content/postsDetail?postId=1000088581)的“十一、幻想真境剧诗”段落，原始公告账号未认证，两份转载可能共用同一原稿，不算独立事实起源。各包内保存实际读取段落及哈希。10月来自已有资料包，其上游包含公告转载和攻略；没有将攻略支持字段改称官方验证，也没有把仓库导入当作新增外部独立确认。

## 历史适用边界

访问日期是2026-10-10；页面更新标签不等于首次发表日期。当前可读revision是回顾性材料，没有取得当时的完整快照。全部`published_at`保持空，`contemporaneous_snapshot`和`blind_backtest_eligible`保持false。revision_id、哈希只能证明读取/冻结对象，不能证明当时可见、事实真实或策略成功。

`当期`页面虽标2026-10-05更新，正文仍写2026年8月、第26期；因此没有用于9月或10月。2026年归档同样实际只到8月。不能因地址含“当期”而升级来源时效。[现有10月资料](../seasons/2026-10-v7.1.json)以独立来源类别导入10月包，并保存源文件哈希、原始事实记录、上游URL、复核日期和冲突。此次读取/导入日期不会刷新上游2026-10-08复核日期。

规则按历史边界分三组：2024-07/08为`initial-8`，2024-09至2025-09为`visionary-10`，2025-10起为`lunar-12`。前两期不能套用后来新增的辉彩祝福；后期有圣牌不能向前套用。最高演出幕数和圣牌数量记录在各包的`rules_provenance`中。前26期游戏版本保持null；9月的7.0来自明确排期的公告转载，10月的7.1继承已有正确期次资料记录，均登记来源支持级别，不由月序猜测。

[规则研究登记](../seasons/history/research-provenance.json)区分已读当前规则的历史标签与仍需原始公告复核的日历边界。当前BWIKI明确写辉彩祝福为5.0新增、特邀角色祝福增益为5.2新增、星章奖励从2025-06第12期开始。5.2的特邀增益不得仅因版本在11月发布就套到整个2024-11期。当前新版分支与数值没有批量回填旧月份。

## 策略与回测限制

这些包是事实输入，不是成品攻略。没有阅读每期普通候选池、敌人完整机制/抗性/HP、角色历史解锁时间、完整增益分支，也没有历史账号与随机招募流水；固定敌人名字不能独自证明需要什么对策，合法排布不能证明战斗输出足够。

本研究者未主动打开专家攻略；搜索服务却返回过非请求的专家攻略片段，涉及2024-07、2025-10等月份，不能认证严格盲测知识状态。因此没有由本研究者生成或冻结“未受专家信息影响”的历史策略。独立重建、专家对照、合成约束验证、真实通关必须分别登记，后续规划可使用这些明确标为回顾性的事实包。
