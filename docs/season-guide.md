# 每期一图流交付标准

用户于2026-10-10指定凝渡_Du的一图流为产品格式基线。目标是每期一张准确、信息密集、可直接照着打的攻略图。逐步对话、内部检查和存档服务于此交付，不替代完整攻略。

## 固定格式

沿用参考图的表格结构：每幕一行，列为「幕次｜阵容排布｜怪物推荐｜开打前｜打完选」。圣牌等额外目标按本期流程插入对应位置；不能把参考图的10幕硬套到其他难度或新期次。底部为「Buff推荐」和「大哥/好友助战角色推荐」，重要通用提醒放侧边。标题标明年月、难度、目标、修订时间，以及通用版或账号适配版。

| 区域 | 必须包含的决策信息 |
|---|---|
| 阵容排布 | 主推荐队伍；可弹性位置用清楚的角色职能/元素表示；机制必需位、关键留人和真实替代明确写出。核对全程耐力，不能各幕单独看起来合理却互相冲突。 |
| 怪物推荐 | 本幕优先选择的敌人，配真实游戏截图/可核实图标与名称；简写也要能辨认。说明关键机制和选错风险。随机池未出现推荐敌人时给可执行备选/避选条件；固定Boss明确标注。 |
| 开打前 | 此阶段优先招募谁/什么岗位、选择什么事件或Buff、必要等级/分支和停止投入条件；发生在别的阶段的操作不能塞到本格。 |
| 打完选 | 本幕结算后优先补的角色/岗位、Buff、资源选择及影响下一幕的条件；这是选择规则，不宣称随机选项必定出现。 |
| Buff推荐 | 优先级、前中后期升级节奏、关键等级、二级/四级等分支方向及其适用条件；所用简称与游戏选项对应，依赖的当前效果可追溯。 |
| 助战推荐 | 可辨认角色头像、推荐顺序、关键命座/配置/机制条件、安排到哪些幕，以及借不到时的备选。不得默认用户好友拥有某角色或默认低练度能复制高配置结果。 |
| 通用提醒 | 真正影响选择的事件规则、刷新/资源预算、保留角色或必要操作；简短具体。 |

不确定处不能补造。公开事实缺口由Agent研究；随机现场、账号和好友库存才向玩家询问。公共通用版可先交付，不强迫用户先录完整账号；无法保证的适用范围必须写明。账号适配版仅修改受账号影响的队伍/助战/路线。

## 内容准确性与证据

以用户参考图为布局基线，以凝渡当期及往期材料作攻略参考。往期只用于抽取格式和策略思路；怪物池、开幕/特邀角色、Buff效果/等级/分支每期重新核对。保持AGENTS.md的事实优先级；攻略推荐不自动成为游戏机制事实或已通关证据。

图中所有影响选择的条目保留可追溯底稿：期次、难度、来源URL、视频时间点/图片位置、读取范围、核对日期、主张类型、适用条件和冲突。视频只读到简介就标简介，不声称已核对画面。不同难度/版本不能混用；冲突未仲裁时给已核实的安全替代或明确未完成。

敌人与角色图片必须核对身份和来源；不能用AI生成图冒充游戏截图。文字与表格用确定性排版，先核实内容，再布局并检查手机放大后的可读性。参考来源清楚署名；不要冒用原作者身份或复制水印伪称原创。

## 验收与每期更新

1. 覆盖目标难度全部幕与额外挑战，顺序与游戏一致；五个逐幕栏、底部两区和关键提醒齐备。
2. 每个建议能对应游戏中的具体选择；敌人图文匹配；Buff等级/分支无错季；助战配置与可用性条件明确。
3. 对整条路线核对开幕与招募条件、耐力、角色保留、资源和随机未出现时的备选；区分预计路线与已经取得/已经通关。
4. 不能用「高练C」「随便打」等空泛用语掩盖实际缺失；可弹性位置需注明职能与必要强度条件。不把有条件的路线写成必过。
5. 交付一张完整可读图并供用户审阅内容；保留可追溯底稿。关键缺口未关闭时标草稿及具体缺口，不能称完整/准确已验收。
6. 真实照图使用反馈另记为实战证据；图片完整性、事实准确性审查和真实通关分别记录，不互相替代。

新期复用结构与已验证制作方法，重新取得当期内容。用户提供现场变化时只修订受影响行与全程资源依赖，更新版本，不要求每幕都重新对话。

## 内容质量门（one-image-v2）

复用现有JSON/离线导出器；`src/guide_editorial.py`只拦截已知可判定错误，不新增框架。玩家行只投影六个显示字段，来源、计算、角色能力与审查笔记留在底稿/离线HTML。字数预算与内部术语拦截用于收敛文案；不能以字数合格证明内容正确。

每幕需当期非模板来源及mechanic/route/recruitment审查。独立mechanic_spec覆盖所有目标并约束行要求，防止删掉治疗/附着要求后继续通过；全队扣血必须有party_heal，盾、抗打断和仅场上治疗不能替代。风套需四件套、佩戴者在场扩散、目标元素与刷新覆盖。高频冰不能仅以冰元素标签满足。助战需独立强度、机制、命座、配队审查和完整条件换线；Buff需当期效果、优先级、分支审查。

制作者每期先取得当前文本/画面，再填写能力标签和审查字段，逐项人工核对；来源URL或reviewed标签本身不能证明事实。导出器保证合同和布局，不自动判定DPS、截图语义、仇恨稳定性或攻略最优。成图后检查整图和头像换线说明，最后交给用户评审，真实照图通关另记。

阵容文本须显式标出合同必需岗位（群奶/全队治疗、奶/治疗、弓、后台冰、风套），不能仅在隐藏能力标签里正确。该词表只检查岗位是否呈现，不能理解角色名或验证实际配置；具体角色能力仍须人工核对。
