# Game UI asset provenance

These are identified game UI icons, not generated imagery or claims of gameplay screenshots.
Each image's source URL, identity, review date and SHA-256 are recorded in `../2026-10.json`.
The public game-resource mirrors are Alioth (monster icons) and Enka (character icons);
the underlying game art belongs to HoYoverse. No mirror is represented as an official publisher.
The exporter works offline with these reviewed files and fails on changed/missing assets.

`NotoSansSC-Regular.otf` is Noto Sans CJK SC from the upstream notofonts/noto-cjk
SubsetOTF/SC distribution. Its redistribution license is in `OFL.txt`.
Upstream: https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC
